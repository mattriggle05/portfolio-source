https://github.com/iconify/icon-sets/blob/master/json/simple-icons.json

## Arena

arena.svg is retained unchanged from:
https://github.com/Mr-Nobody-Anonymous/arena-ai-android/blob/main/official_favicon.svg

This is an unofficial client repository identifying the asset as the official favicon. Direct requests to arena.ai returned HTTP 403; authenticity against the live official asset has not been independently verified.

All icons are served locally; no runtime icon service or icon package is required. Devicon and Lobe Icons license files remain as historical attribution for previously used assets.
