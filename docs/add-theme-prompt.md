Create and implement one new visual theme for this portfolio, adding it to the existing on-page style selector.

Start from the latest `codex/style-switcher` branch and create a new branch named `codex/add-theme-<short-name>`. Read the README, `src/themes/registry.ts`, the shared layout, and the existing themes before editing. Choose a distinctive, cohesive direction using your own design judgment.

1. Create `src/styles/themes/<short-name>.css`. Use an existing theme as a completeness reference, but develop a new visual identity. Each theme must work independently over the shared structural defaults; do not import another theme.
2. Put new decorative assets under `public/images/themes/<short-name>/`. Use those namespaced absolute paths in the CSS and registry. Supply a portrait asset and accurate alternative text; hidden portraits still need valid metadata.
3. Import the stylesheet with `?url` in `src/themes/registry.ts` and append one entry with a unique, stable, lowercase URL-safe `id`, a readable `label`, `stylesheet`, `portrait`, and `portraitAlt`. Preserve all existing IDs and entries and keep the current default first. The selector, stylesheet links, URL validation, and portrait switching derive from this registry; do not add theme-specific logic to them.
4. Preserve every existing page component, its content and order, internal arrangement, all eight grid areas, outer dimensions, the 12-column / 7-row grid, aspect ratio, and grid gaps. Keep `src/styles/layout.css` and the shared component structure unchanged. You may style padding, typography, colors, rounding, borders, shadows, hover/focus treatments, and decorative SVGs/backgrounds. Keep artwork in its existing reserved slots. Scope styles to the portfolio so the comparison selector remains usable.
5. Run `npm run build`, `npx astro check`, and `git diff --check`. Verify in a browser that the new theme appears automatically in the selector, switching to and from existing themes works, `?style=<id>` restores it after reload, and invalid IDs fall back to the default. Inspect at desktop and 640px widths for overflow, clipping, readable text, focus visibility, and unchanged tile geometry. Disclose any failed or unavailable checks.
6. Commit the finished addition and report the branch, commit, theme name, URL key, design choices, and validation results. Do not merge or publish.
